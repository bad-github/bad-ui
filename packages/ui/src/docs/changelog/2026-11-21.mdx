# 2026-11-21 · v0.0.5 · 主题切换动画与组件效果预览

## 新增

- **ThemeToggle** 新增 `animation` 属性，可选 `none`、`circle`、`dots`，默认 `none`，保留直接切换主题的行为。
- `circle` 使用 View Transition API，从按钮中心圆形扩散覆盖页面，持续约 1 秒；浏览器不支持时直接切换。
- `dots` 使用 Canvas 绘制点阵幕布，从按钮中心向外铺开；切换主题后，再从中心向外消散，持续约 1.04 秒。幕布颜色读取当前主题背景变量，图标继续使用现有 SVG。

```tsx
<ThemeToggle animation="circle" />
<ThemeToggle animation="dots" />
```

## 交互与清理

- 动画遵循系统“减少动态效果”偏好；页面隐藏时直接完成主题切换。
- 动画期间忽略重复切换，保留调用方通过 `onClick` 的 `preventDefault()` 取消切换的能力。
- 点阵动画结束或页面隐藏时，清理 Canvas、动画帧、定时器与监听，移除全页动画标记。
- 点阵消散方向调整为从按钮向外推进，避免新主题向按钮中心收拢。
